# Starter-pack issues found and fixed

The brief says the starter code is a scaffold and that issues in it should be diagnosed and fixed. Each issue was reproduced before it was fixed, and each fix is covered by a test.

| # | Issue | Impact | Fix | Test |
|---|---|---|---|---|
| 1 | `evals/run_public_evals.py` assumes the mock API is already running (started separately by `run_local.py`). | Run on its own, every vendor lookup fails. A correct "cannot verify, so escalate" answer then fails PUB-01, which forbids `vendor_risk_unavailable`. Results depend on whether a second terminal happens to be open. | `src/local_services.ensure_vendor_api()` uses the configured API if it is healthy; otherwise it starts the mock API over real HTTP on a free port in a background thread and points the client at it. Called by the eval runners. | `test_vendor_client.VendorClientOverHttpTests` |
| 2 | `vendor_client.get_vendor_risk` only calls `raise_for_status()`. | Callers can't tell "vendor has no record" (404) from "service down" (503), a timeout, a refused connection or a malformed body. Policy §10 requires these to be recorded and never read as favourable. | `fetch_vendor_risk()` returns a typed `VendorRiskResult` (`ok` / `not_found` / `unavailable` / `error`) with the HTTP status, detail, endpoint, attempts and latency. Retries once on connection errors, timeouts and 5xx. The old `get_vendor_risk()` is kept as a compatible wrapper. | `test_vendor_client` (200, 404, 503 + retry, refused, timeout, non-JSON, recovery on retry) |
| 3 | The mock API calls `unquote()` on a path parameter FastAPI has already decoded, and the route doesn't accept `/`. | A vendor named `Acme%Co` is looked up as something else. A name containing `/` hits the router's generic 404, which looks the same as "vendor not found". | Removed the second decode; the route uses `{vendor_name:path}`. | `test_percent_sign_in_name_round_trips`, `test_slash_in_name_reaches_handler` (over real HTTP; the in-process `TestClient` decodes paths differently, so it can't test this) |
| 4 | `pandas.read_csv` turns blank cells into `NaN`. | `NaN` is truthy, so `if row["security_review_date"]` treats a **missing** security review date as present. The same happens with blank `manager_id`. Numeric columns change type when blanks appear. | CSVs are loaded with `dtype=str, keep_default_na=False`; numbers are parsed with `to_number()`, which returns `None` for blank, null, NaN and non-numeric values. | `test_data_access.NullHandlingTests` |
| 5 | The org data doesn't map cleanly to "Department Head". Robert King (E007), who manages the Sales and Customer Success staff, is in "Go To Market", which has no budget row. Operations has only a VP. | Looking up a department head by department name fails for Sales and Customer Success requesters. A Director requester would be their own approver. | `resolve_approvers()`: Manager = direct manager; Department Head = first Director/VP **strictly above** the requester in the reporting chain. Cross-department or unresolved approvers are reported as notes, so a human assigns them rather than the system guessing. Cycle-safe. | `test_data_access.ApproverResolutionTests` |
| 6 | Data paths are hard-coded to `./data`, and the mock API loads its data once at import. | The system can't be run against a different snapshot (hidden-case data, our edge-case fixtures) without editing files. | `PROCUREMENT_DATA_DIR` (via `src/config.py`) is used by the data layer and the mock API; the API reads its file per request. | `test_data_access.ConfigurableDataDirTests` |
| 7 | The reference date (2026-09-30) only appears as text in the policy. | It's easy to fall back to the computer's date by mistake, which the README forbids. | `config.get_reference_date()` parses it from the active policy file, falling back to 2026-09-30 only if the line is missing. | `test_reference_date_follows_policy_file` |
| 8 | `run_local.py` starts Streamlit without `--server.headless`. | On a fresh machine Streamlit stops at an interactive "enter your email" prompt, so the one-command start never serves the UI. | Starts Streamlit headless with usage stats off, and prints the URL to open. | Manual: `python run_local.py` → UI returns HTTP 200 |
| 9 | `run_local.py` hard-codes API port 8001, while the client reads `VENDOR_RISK_BASE_URL`. | Changing the URL in `.env` silently breaks every vendor lookup. | The launcher takes its host and port from `VENDOR_RISK_BASE_URL`. | Manual |
| 10 | `tests/` has no `__init__.py`. | `python -m unittest` from the project root finds **no tests** ("NO TESTS RAN"); tests only run with `discover -s tests`. | Added `tests/__init__.py`. | `python -m unittest` runs the full suite |
| 11 | `verify_setup.py` hard-codes `./data`. | Preflight could pass on the bundled data while the app runs on a different snapshot. | Preflight checks the active data dir (`PROCUREMENT_DATA_DIR`) and prints which one it checked. | Manual: pointing at a missing dir fails preflight |

The output contract (`src/contracts.py`) and the `handle_request(request_id, architecture)` adapter signature are unchanged.
